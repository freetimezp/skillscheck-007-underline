# Skill Check 007 — Underline Animation & Animated Pseudo-elements

A responsive, vanilla HTML/CSS/JavaScript quiz for the learning roadmap.

## Features

- 20 randomized questions and shuffled answer options
- Single-choice and multiple-choice questions
- Code snippets, instant feedback and explanations
- Progress indicator, results summary and retry
- Saves attempts, latest score and best score to shared localStorage

## Run locally

Open `index.html` in a browser, or use a local development server.
